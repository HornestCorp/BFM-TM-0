# BFM-TM

## Description

**BFM-TM (Base Form Model — Talking Model)** is an experimental character-level language model developed using Python and PyTorch.

The main goal of BFM-TM-0 is to learn how to generate coherent and natural-sounding text. It is an early-stage project focused on language generation, vocabulary, and text coherence.
